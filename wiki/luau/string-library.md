# `string` Library

**Status:** stub

Standard string utilities plus Luau extensions. Key functions: `format`, `gsub`, `match`, `find`, `sub`, `len`, `rep`, `upper`, `lower`, `split` (Luau extension).

Also: string interpolation syntax `` `Hello {name}` ``, integer formatting via `%d`/`%x`, and `string.pack`/`string.unpack` for binary encoding.

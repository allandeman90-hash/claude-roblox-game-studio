# Lua Scripting Starter Guide

**Author:** DarkSinisterPVP (Dark)
**Helper:** Supersaiyan122
**Posted:** November 24, 2019

## Overview

This comprehensive beginner's guide covers fundamental Lua programming concepts for Roblox development, emphasizing that mastering programming requires patience, consistent practice, and persistence.

## Key Topics Covered

**Basic Functions:**
- `print()` — outputs strings, numbers, and equations
- String concatenation using `..` operator
- Arithmetic operators: `+`, `-`, `*`, `/`, `^`, `%`

**Variables & Scope:**
- Global variables (accessible throughout script)
- Local variables (limited to code blocks)
- Naming conventions (letters, numbers, underscores; no capitals/spaces)

**Control Flow:**
- If statements for conditional execution
- While loops for repetitive execution based on conditions
- For loops with customizable increments
- Repeat/Until loops
- Break statements to exit loops

**Functions:**
- Function definition and execution
- Parameters and arguments
- Code blocks and indentation

**Data Structures:**
- Tables/Arrays for storing multiple values
- Index-based access (starting at 1)

**Additional Concepts:**
- Comments for code organization
- Properties and object manipulation
- Booleans and relational operators (`==`, `~=`, `>`, `<`, `>=`, `<=`)
- Local scripts vs. server scripts

# Using the MicroProfiler & MicroProfiler Documentation

**Author:** Mullets_Gavin (Mullets)
**Posted:** February 28, 2021

## Content Overview

The original post announces two comprehensive guides on utilizing Roblox's MicroProfiler tool:

1. **"Roblox: Using the MicroProfiler"** — Covers tool usage, profile dump generation, and application purposes
2. **"Roblox: MicroProfiler Documentation"** — Details labels and their meanings

The author describes this as "the most under-utilized tool" for streamlining debug development.

## Key Usage Patterns Discussed

**Opening the profiler:**
- Keyboard shortcut: `Ctrl + F6`

**Pausing profiler data:**
- Keyboard shortcut: `Ctrl + P` (when profiler is active)

**Studio considerations:**
- The tutorial targets gameplay profiling, not Studio analysis
- Users must disable "Respect studio shortcuts when game has focus" setting (accessible via Alt+S) to use in-game keybinds within Studio
- Studio profiling is noted as unreliable for performance analysis

## Notable Comment

A community member praised the resource: "you are a great-send for the MicroProfiler documentation outlining the labels and what they represent," highlighting the lack of official documentation prior to these guides.

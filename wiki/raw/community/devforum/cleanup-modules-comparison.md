# Best Cleanup Module to Use - Maid vs Trove vs Janitor

**Author:** soprosostupid (wavim)
**Posted:** December 4, 2023

## Overview

A community discussion seeking recommendations among three popular cleanup modules—Maid, Trove, and Janitor—for managing connections and preventing memory waste.

## Key Comparison Points

The response from icy_oasis outlined these modules:

**Maid:** Described as "the rawest implementation" by Quenty, offering basic cleanup functionality.

**Janitor:** Equipped with additional methods, notably "an option to define a method used at cleanup" and compatibility with custom signals.

**Trove:** Maintains feature parity with alternatives while being actively maintained alongside a TypeScript version.

## Important Context

All three libraries are:
- Maintained and reliable
- Created by reputable developers
- Documented with source code available
- Suitable for production use

The consensus emphasized that the "best" choice depends on personal preference and coding style rather than objective superiority.

## Thread Resolution

The OP decided to use Janitor, citing appreciation for its cleanup method customization and signal integration capabilities.

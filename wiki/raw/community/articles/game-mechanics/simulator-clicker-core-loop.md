# Clicker Simulator Games - Core Mechanics

## Core Components

**Backpack System**: Stores the "clicks" that players generate, which are then sold in designated areas for currency.

**Clicker Tool**: The primary mechanic that enables players to generate clicks through interaction.

**Pets**: Provide gameplay bonuses, typically "a greater coins multiplier" or other stat enhancements.

## Rebirth System

Rebirths function as a progression reset mechanic. "Once you reach enough coins and/or any other value, you are given the option to have your stats and inventory reset in exchange for a special perk."

Key features:
- Optional stat and inventory resets in exchange for multiplier bonuses
- Flexible implementation -- rebirths do not necessarily reset everything; some games preserve inventory or remaining coins
- Escalating costs where "each rebirth generally costs more than the previous one"

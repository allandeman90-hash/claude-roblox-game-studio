# Multiplier & Prestige Systems

## Multiplier Implementation
- Store multiplier values in a table
- Recalculate dynamically when conditions change (pet equip, rank change)
- "Simply storing a multiplier value is sufficient"

## Stacking Examples (from game wikis)
- Super Power Training Sim: x32 multiplier = 3,200 per second at training locations
- Multipliers stack with each other
- Each prestige can double the rebirth multiplier

## Prestige Progression Stages
Example from Run to Speed Simulator:
Rebirths -> SuperRebirths -> Prestige -> Majesty -> Ascension ->
Transcendence -> Expansion -> Absorption -> Reincarnation -> Divine ->
Loyalty -> Sacrifice -> Darkness

## Grow a Garden Prestige
- Reset level, award permanent bonuses
- Higher crop yield multiplier
- Faster growth times
- More currency per harvest
- Each prestige stacks up to 10 rebirths

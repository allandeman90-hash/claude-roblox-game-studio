## Capture Methodology

All files were pulled verbatim from the `Roblox/creator-docs` GitHub repository on the `main` branch
(path prefix: `content/en-us/`). Each file is wrapped in a frontmatter block containing:

- the original `create.roblox.com/docs` URL
- the matching `github.com/Roblox/creator-docs` source URL
- capture metadata (agent, date, subcategory, tags)

The body of each file preserves the original markdown content (minus the source's own YAML frontmatter).
Custom JSX components used by the Roblox docs site (`<Alert>`, `<Tabs>`, `<Grid>`, etc.) are preserved inline
because they frequently contain prose that is part of the best-practice guidance.

## Scope Coverage

Every topic listed in the research-agent-4 scope is represented:

- **Security & anti-exploit**: `security/` (11 files) covers server-authority model, client-server boundary,
  remote validation, network ownership, access control, defensive design, detection, third-party
  vulnerabilities, HttpService hardening, and secrets store.
- **Performance**: `performance/` (13 files) covers MicroProfiler (all modes), Script Profiler,
  streaming, task scheduler, tag reference, design/identify/improve/monitor workflow.
- **Publishing**: `publishing/` (14 files) covers publish workflow, genres, icons, thumbnails,
  descriptions, accessibility, adaptive design, badges, account verification, configure, version history,
  update rollout, teleport, place files.
- **Monetization**: `monetization/` (15 files) covers passes, developer products, subscriptions,
  commerce products, engagement-based payouts, immersive ads, paid access (both currencies),
  private servers, regional pricing, price optimization, Roblox+, virtual items, and the canonical
  ProcessReceipt / player-data-purchasing idempotency guide.
- **Open Cloud & persistence**: `open-cloud/` (33 files) covers the full DataStore / MemoryStore /
  Messaging Service surface - both the REST open-cloud API (api-keys, OAuth2, throttling, request-handling,
  usage guides) and the Luau-side services (best practices, session locking, error codes and limits,
  versioning, caching, observability, hash-map/queue/sorted-map, cross-server messaging).
- **Assets**: `assets/` (8 files) covers the full asset pipeline, Asset Manager, Toolbox,
  packages, privacy/permissions, in-experience asset creation, monetization, Creator Store API.
- **Devices**: `devices/` (8 files) covers cross-platform design, input action system,
  mobile/gamepad/mouse+keyboard, console guidelines (Xbox/PS), VR guidelines.
- **Compliance**: `compliance/` (11 files) covers content maturity, experience guidelines,
  advertising standards, regional content availability, chat guidelines, text chat, voice chat,
  GDPR/CCPA, DMCA, rights manager, and GDPR right-to-be-forgotten.

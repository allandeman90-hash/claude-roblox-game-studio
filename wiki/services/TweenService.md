# TweenService

**Status:** stub

Smooth interpolation of Instance properties over time. `TweenService:Create(instance, tweenInfo, propertyTable)` returns a `Tween` you can `:Play()`, `:Pause()`, `:Cancel()`.

`TweenInfo` controls duration, easing, style, direction, repeat count, reverses, delay.

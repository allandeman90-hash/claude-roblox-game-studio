# TextChatService

**Status:** stub

Modern Roblox text chat system (replaces legacy `Chat`). Provides channels, commands, bubble chat, and automatic filtering. Customize via `TextChannel`, `TextChatCommand`, `ChatWindowConfiguration`, `BubbleChatConfiguration`.

All player-sent text is auto-filtered. Dynamic text you display must go through `TextService:FilterStringAsync`.

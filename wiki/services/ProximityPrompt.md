# ProximityPrompt

**Status:** stub

Built-in contextual interaction UI. Attach to any part; when a player gets near, a prompt appears. Handle `Triggered` server-side to react to player activation.

Properties: `ActionText`, `ObjectText`, `HoldDuration`, `MaxActivationDistance`, `RequiresLineOfSight`.

Preferred over `ClickDetector` for interactive objects.

# Wally Package Manager

**Status:** stub

## Summary

Wally is the standard Luau/Roblox package manager. `wally.toml` declares dependencies; `wally install` fetches them to `Packages/`. Integrates with Rojo via a project.json mapping.

Major community libraries available via Wally: GoodSignal, Trove, Matter, Knit, ProfileService, TestEZ.
